# Smoothing report

Generated by `python art/blender/sprites.py --smooth`. Every model was rebuilt with the same camera, lights, resolution (256×256), transparent film and filter width 1.5. Only the body shapes changed; designs, colours and poses are unchanged.

Files per model: `assets/sprites/<name>_smooth.webp` and `<name>_side_smooth.webp` (new renders, next to the originals); `art/blender/blend/<name>[_side]_backup.blend` (before) and `<name>[_side]_smooth.blend` (after).

**Every mesh:** merged vertices by distance (0.001) and recalculated normals outside.

**Fused body (one per model):** body parts joined → open ends capped → curved parts rounded (subdivision 2, edges sharper than 50° creased) → Voxel Remesh (0.6% of the model size) → light step smooth (0.5 × 4) → colour layer → Data Transfer of each part's exact colour from the hidden original parts → Subdivision Surface (viewport 1, render 2) → Smooth by Angle 30° → outline.

**Kept separate (unchanged shapes):** gear and accessories (capes, hats, hoods, wings, halos, crowns, weapons on monsters), and details: eyes, highlights, blush, glowing or metallic parts.
